CSS 3D Clickable Flip Cards

This project recreates a premium product landing page using CSS 3D flip cards with interactive click-to-flip behavior.

Files:
- task1.html: page structure and card content
- task1.css: styling and 3D animation behavior

How to view:
1. Open task1.html directly in a browser, or
2. Serve the folder with any local static server.

Example:
python -m http.server 8000
Then visit http://localhost:8000/task1.html

Design notes:
- 3 modern product cards with layered gradients and photography
- Clickable labels flip each card to reveal product details
- Responsive layout and polished, premium styling
